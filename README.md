# Plumbline

Plumbline is a Codex-native engineering workflow plugin for keeping product intent, implementation, verification, and repository documentation aligned.

This repository is the implementation workspace. The approved product specification and live handoff plan are in:

- [`docs/specs/plumbline-v1.md`](docs/specs/plumbline-v1.md)
- [`docs/plans/plumbline-v1.md`](docs/plans/plumbline-v1.md)

The plugin is not installable from this repository until the implementation reaches its release checkpoint. Installation instructions will be added when the package is ready.
