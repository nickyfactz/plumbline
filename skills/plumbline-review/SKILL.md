# Review

This is the explicit user-facing wrapper. Select the `plumbline-review-engine` through the host's skill dispatcher when available. Otherwise read `../plumbline-review-engine/SKILL.md` relative to this skill and follow it directly. For material code, run the maintainability review before acceptance QA. Do not edit code, tests, snapshots, dependencies, or plans while reviewing.
