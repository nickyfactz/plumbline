# Routing expectations

Each prompt selects one path only. Direct work creates no Plumbline artifacts. One-off explicit phase use never creates a router. An explicit `$plumbline` front-door invocation in an uninitialized fixture hands off to `$plumbline-init` for a read-only setup proposal; it does not write before approval. Automatic routing is available only when the initialized fixture contains `.agents/skills/plumbline-router/`. Review is report-only. Closeout requires acceptance before deleting transient artifacts.

Shape capability requests research external options before asking the user to choose, using cited conclusions rather than an exhaustive catalog. Shape keeps vague future possibilities in fog and does not force them into product questions. A shaping handoff is offered only for clearly long-running work, created only after approval, updated only at material checkpoints, and promoted into the one active specification rather than duplicated.
